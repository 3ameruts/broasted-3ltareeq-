# «جديدنا!» — إعلان إطلاق الطلب الأونلاين (v2)

‏1080×1920، 33 ثانية، كل مشهد بيبلّش على إيقاع «Upbeat Jazz» (Mixkit؛ الدروب على 2.6 ثانية).

| الوقت | المشهد |
|---|---|
| 0–2.6 | تشويق على مسرح غامق: «عنّا خبر حلو…» «جاهزين؟» |
| 2.6–7 | «جديدنا!» مع كونفيتي، «صار فيك تطلب أونلاين!»، الجوال بيلف 3D |
| 7–15.7 | طلب حقيقي خطوة بخطوة (ستيكرات مرقّمة): المنيو، الوجبة، قسّم الحار والعادي، السلة، الاسم والعنوان، الكود، «انبعت الطلب» |
| 15.7–23.3 | الطلب بيطير لشاشة الفرع، الفرع بيقبل، «تم تأكيد طلبك» (مشاهد الفيديو الأول) |
| 23.3–27.7 | المطبخ: صور أكل حقيقية |
| 27.7–32.7 | اللقطة الختامية مع ستيكر «جديد» وكونفيتي والرابط |

```bash
npm ci && npm run sound
REMOTION_BROWSER=/opt/pw-browsers/chromium_headless_shell-1243/chrome-headless-shell-linux64/chrome-headless-shell npm run render
```
مشاهد الفرع والمطبخ واللقطة الختامية منقولة من `video/online-order-reel` (`src/reel/`). الموسيقى والمؤثرات من Mixkit وما بتنحفظ بالريبو.
